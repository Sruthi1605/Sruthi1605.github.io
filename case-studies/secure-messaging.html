Secure Messaging via Steganography

A messaging tool that hides AES-encrypted messages inside ordinary image files — so the message travels as a normal-looking picture.

Security 2024 Cryptography
  • Python
  • AES
  • LSB Steganography
  • HTML / CSS

01. Overview

Encrypted messages still look suspicious — an intercepted ciphertext is an obvious "something is hidden here" signal. Steganography solves that by hiding the secret in plain sight.

I built a tool where a user encrypts a message and hides it inside an image; the recipient extracts and decrypts it. On the outside, it's just a picture.

"Cryptography protects the message if it's found. Steganography tries to make sure it's never found at all."

02. The Problem

  • Visible ciphertext invites interception and blocking.
  • Sending secrets over chat apps leaves traces on the wire and on servers.
  • A practical secure channel should look completely ordinary.

03. My Role & Approach

  • Encrypted the message with AES before hiding it, so the embedded data is already unreadable.
  • Used LSB (Least Significant Bit) steganography to embed the encrypted bytes into pixel data with minimal visual change to the image.
  • Built the user interface so anyone can pick a message, upload a carrier image, and get a hidden image to share.
  • Implemented the decoder to extract and decrypt the message back to its original text.

04. Key Challenges

  • Capacity vs. invisibility: more hidden bits means more distortion — balanced payload size against detectable artifacts.
  • Integrity: ensured hidden data survives image encoding/decoding without corruption.
  • UX: wrapped a crypto + stego pipeline in a clean interface a non-technical user can operate.

05. Results & Impact

  • End-to-end secure messaging: encrypt → hide → share → extract → decrypt.
  • Owned the frontend interface plus the AES encryption and image-embedding implementation.
  • A practical taste of building security features into a real application.
